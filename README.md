# How to set the VM up 🎉

---

Step 1: Boot up your phone.

Step 2: You should see this menu.

<img width="695" height="424" alt="IMG_7026" src="https://github.com/user-attachments/assets/e97fbb42-e27b-49bd-8cb9-b9a155548bb0" />

This is called the ISOLINUX menu, this is where you will be setting up your VM.

Step 3: At the ISOLINUX menu, click Select VESA MODE (ISOLINUX) (or press Down twice + Enter) to boot Live CD - VESA mode.

Initial x86 Dalvik & Zygote startup takes roughly 30–60 seconds in WebAssembly. Once booted, You can save a Snapshot to resume instantly in future sessions. (Optional)

It may take a lot of time to finish loading. But once we see the bootup screen, you have just did everything correctly.

Click inside the Nexus One display to steer the Android cursor and drag the Froyo lockscreen tab right to unlock. Use the capacitive chin keys or your physical Esc (Back) and Home keys.

Congratulations, you have successfully set up your android 2.2 VM 🚀🎉
